## 만든 이유 · 반영한 것

- 지식·정보가 중요한 시대에 자신의 경험·정보·아이디어를 충분히 정리·활용하지 못한다는 문제의식을 **환경의 필요** 로 썼습니다. 훈계 질문(「정말 그렇게 다뤘습니까」)은 뺐습니다.
- AI가 많은 일을 더 능숙하게 처리할수록 자신의 경험에서 고유한 관점과 통찰을 키워야 한다는 생각을 **전망** 으로 썼고, 「AI와 경쟁해야 하는 상황에서도 자기 기록을 바탕으로 AI의 제안을 판단한다」는 뜻을 남겼습니다. 인간의 우월성이나 미래를 확정 사실처럼 쓰지 않았습니다.
- 「개인 지식 운영 체계」가 컴퓨터 운영체제가 아니라 제작자의 명칭임을 소개 페이지와 README 에 적었습니다.
- 현재 앱은 그 환경을 만들어 가는 기록 도구라고 썼고, 자동 분석·개인화 AI·통찰 생성 기능이 있는 것처럼 쓰지 않았습니다.
