# PKOS 작업 이어가기

기능 기준은 `83e87d9`, 사이트 제작 보류 결정은 `cd63cc7`이다. [현재 상태](현재상태.md)에서 구현과 검사 범위를 먼저 확인한다. 현재 기준이다.

## 실행과 배포

공개 앱은 https://legoschool.github.io/pkos/ 이며 PC 연결 앱은 http://127.0.0.1:8788/?localBridge=1 이다. `main` 반영 후 `.github/workflows/deploy-pages.yml`의 성공과 공개 파일을 확인한다. 둘 다 확인한다. 개인 기록, 실행 로그와 임시 검사 자료는 배포 파일에 추가하지 않는다.

## 수정할 때 지킬 것

편집 중 DOM이 본문의 기준이다. 저장이나 블록 읽기 전에 `syncFromPaper()`를 적용한다. 입력을 보존한다. IME 조합 중 `renderBlocks()`로 편집창 전체를 다시 만들지 않고 삽입과 개별 첨부 갱신 경로를 쓴다. 텍스트 외 블록은 `atomStore`의 식별자와 참조를 유지한다.

이전 저장 키와 기록 필드는 호환성을 위해 남아 있을 수 있다. 화면에서 메뉴를 없앴다는 이유로 기록 값을 일괄 삭제하지 않는다. 원본을 보존한다. 파일 이름 변경은 경로와 첨부 참조, 충돌 및 실패 복구를 함께 다룬다.

## 검사

`local-service/check_knowledge.py`는 탐색과 설정, `local-service/check_editor_media.py`는 편집과 미디어를 검사한다. `python -m unittest discover -s local-service -p 'test_*.py'`는 파일 서비스 회귀 검사를 실행한다. 임시 자료를 쓴다. 실제 사용자 폴더에서 일괄 변경·삭제 시험을 하지 않는다.

## 다음 작업의 경계

사용자 편집 메인과 사이트 제작은 보류 상태다. 별도 기능이나 앱에서 같은 지식 베이스를 공유한다는 결정만 남아 있다. 구현은 미정이다. 실제 모바일 기기, Google 인증과 Drive 왕복, 외부 문서 변환은 환경별 검사가 남아 있다.
