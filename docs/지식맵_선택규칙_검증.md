# 지식맵 선택 규칙 수정

## 지도 중심 화면으로 재구성

상단 설정 줄을 제거하고 짧은 검색창과 보기 설정 버튼을 남겼다. 연결 기준, 검색 범위, 주제 보기와 범례는 오른쪽 패널에 모았다. 패널은 지도의 높이를 줄이지 않는다.

기록 80개와 긴 제목을 넣고 1440px·390px에서 지도 높이가 창의 80% 이상인지 검사했다. 제목은 PC에서 기본 최대 14개, 모바일에서 8개를 겹치지 않게 표시한다. 검색 결과와 선택·마우스 위치의 제목은 우선 표시한다. 전체 제목은 기록 선택 패널에서 읽는다. 관계선은 수가 늘면 옅어지고 선택한 기록의 연결을 강조한다.

관계가 없는 점들은 격자로 배치한다. 서비스 워커 캐시는 map-workspace-v7이다. 아래 선택 규칙 기록은 이전 변경 이력이다.

2026-09-20 로컬 소스에 적용했다. 공개 배포와 실물 휴대폰 설치는 이번 검사에 포함하지 않았다.

## 변경

- PC 검색창은 기본 320px, 최대 400px다. 모바일은 가용 폭에 맞춘다.
- 글 연결과 단어 연결은 현재 선택한 탭을 표시한다.
- 연결 기준, 검색 범위, 이름 표시는 같은 체크박스 표시와 키보드 조작을 사용한다. 전체 선택은 일부 선택 상태도 표시한다.
- 단어 연결에서 글용 조건을 숨기고, 함께 등장한 글 수 조건을 실제 계산에 적용한다. 글 탭의 조건은 전환 후에도 보존한다.
- 전체 보기는 점과 제목의 경계를 계산한다. 배치를 안정화한 뒤 맞추며, 확대·축소 옆에 둔다.
- 범례는 글과 단어의 계산 기준에 맞춰 바뀐다.

## 검증

`docs/점검도구/PKOS_NEW_화면.mjs`를 Edge에서 실행했다. 390·768·1440px 검색창 폭, 탭 전환, 조건 반영, 체크 표시, 제목을 포함한 전체 보기, 편집·저장·재열기 검사를 통과했다.

앱 설치 manifest, 아이콘 응답, 설치 버튼의 모의 요청 호출을 확인했다. 서비스 워커 등록 코드는 유지했고 캐시 버전은 graph-v6으로 갱신했다. 모의 요청은 실제 OS 설치 완료를 뜻하지 않는다.

## 모바일 경계

검사는 PC 브라우저의 모바일 크기 모사다. Android와 iPhone의 실물 터치·설치 검사는 하지 않았다. PC의 localhost 주소와 G 드라이브 폴더는 휴대폰에서 자동 공유되지 않는다. 홈 화면 설치와 기기 간 파일 동기화는 별개다.

수정 소스는 index.html, pkos-new.css, sw.js다. 기존 사용자 기록은 변경하지 않았다.
