# 화면 점검 도구 (고치는 사람용)

**앱을 쓰는 데는 필요 없습니다.** `index.html` 을 고친 뒤 **정말로 동작하는지**
사람이 일일이 눌러 보지 않고 확인하는 도구입니다.

브라우저를 화면 없이 띄워 놓고 진짜로 눌러 봅니다. 사진을 넣고, 모자이크를 칠하고,
펜으로 획을 긋고, 녹음을 켜고, 공유를 보내 봅니다. 그리고 **결과를 픽셀 단위로 확인**합니다.

## 쓰는 법

```bash
node docs/점검도구/화면점검.mjs http://localhost:8000/
```

앱을 먼저 띄워 두어야 합니다.

```bash
powershell -ExecutionPolicy Bypass -File docs/점검도구/띄우기.ps1 -Port 8123
```

| 파일 | 하는 일 |
|---|---|
| `띄우기.ps1` | 저장소를 `http://localhost:8000` 으로 띄운다 (파이썬·노드 서버 없이). 8000 이 막혀 있으면 `-Port 8123` 처럼 딴 자리를 준다 |
| `화면점검.mjs` | **새로 만든 기능**을 눌러 보고 픽셀까지 확인한다. 업노트식 블록·왼쪽 기둥·휴지통·양식·집중 모드·자리 고르기·폰 아래 바까지 (233가지) |
| `구석구석.mjs` | **원래 있던 화면**을 전부 열어 본다. 관계망·엮어내기·설정 6칸·보기 4종·검색·휴지통·다크모드·좁은 화면 (33가지) |
| `이름바꾸기.mjs` | **옛 이름(PKEMS·PEER·TRACE)으로 쌓아 둔 것이 PKOS 에서 그대로 이어지는지** (11가지) |
| `대비점검.mjs` | **일곱 프리셋을 밝은/어두운 · 데스크톱/폰 네 자리에서 재 본다** · 글자 대비·가로 넘침 (14) + **색감 여섯 × 밝기** (12) + **축이 서로 안 흔들리는가** (21) |
| `공유쪽.mjs` | **웹 쪽으로 공유한 링크가 펴지는지** · 영상·녹음 재생기 · 사진 대비책 · 잘린 주소 · **앱 주소를 안 흘리는지** (19가지) |
| `소개페이지.mjs` | 소개 페이지(`intro.html`)가 **쪽으로 제대로 갈리는지** · 한 번에 한 쪽만 · 맨 위로 · 주소로 바로 열기 (27가지) |
| `색감만들기.mjs` | **점검이 아니라 «만드는» 도구.** 색감 여섯의 CSS 를 찍어 낸다. 어두울 때 값이 두 자리에 놓여야 해서, 손으로 두 벌을 쓰면 어긋난다 |
| `색인쪼개기.mjs` | **색인이 커졌을 때 조각으로 나뉘는지 · 무엇보다 기록이 안 사라지는지** · 올린 것을 실제로 들고 있는 가짜 드라이브를 세운다 (22가지) |
| `자료가져오기.mjs` | **폴더를 훑어 글·자료를 색인에 넣는 길** · 가짜 드라이브를 세워 로그인 없이 끝까지. 가져온 «뒤» 고치기·빼기·지우기·길찾기 줄·목록 디렉토리까지. **올라간 사진 가리기 · 폴더 구조 자동 갱신 · 옮긴 자리 다시 잡기** (71가지) |
| `자리와이름.mjs` | **사람이 드라이브에서 옮기고 이름 바꾸고 버릴 때** 앱이 따라오는지 · 가짜 드라이브가 진짜로 움직인다. 폴더 안 옮기기·폴더 이름 바꾸기·폴더째 옮기기·밖으로 빼기·되돌리기·휴지통·이름 되돌림·지울 때 원본·정리 방식 둘·**이름 조각 다섯**·**「📛 이름 정리」 실제로 돌려 보기** · 지웠다 다시 가져오기 · 「기존 파일도 새 방식으로 옮기기」 (64가지) |
