# 강의 녹화 검토

상태: 검토, 미구현

화면을 주 영상으로 두고 웹캠 얼굴을 오른쪽 아래에 합성한다. 얼굴 표시를 끌 수 있게 한다. 마이크 음성을 영상에 포함하고 녹화 중에도 기록을 작성한다. 종료 후 같은 기록 폴더에 영상과 시간별 전사문, 작성한 메모를 묶는다.

브라우저의 화면 캡처, 캔버스 영상 스트림과 MediaRecorder로 합성 녹화를 구현할 수 있다. 화면 공유 시작에는 사용자의 선택과 권한 승인이 필요하다. 컴퓨터 재생 소리 포함 여부는 브라우저와 선택한 공유 대상에 따라 달라진다.

전사는 별도 처리한다. 브라우저 음성 인식은 지원 범위와 서버 연결 여부가 달라 장시간 강의의 유일한 전사 수단으로 삼지 않는다. 실시간 자막은 임시 표시로 두고 종료 후 저장 음성을 다시 처리하는 안을 우선 검토한다. 녹화가 전사 오류 때문에 멈추지 않도록 분리한다.

긴 녹화는 메모리에 전부 쌓지 않고 나눠 저장해야 한다. 로컬 폴더 저장, 중단 후 복구, 화면 공유 종료, 카메라 연결 해제, 음성 누락, 영상과 전사 시간 맞춤을 실제 장비로 검증해야 한다. 전사 엔진은 아직 선택하지 않았다.
