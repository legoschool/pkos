# 강의 녹화

상태: 구현, 합성 미디어를 사용한 브라우저 검증 완료. 실제 장비의 장시간 녹화는 미검증.

수업 중 보여 준 화면과 설명이 사라지지 않도록 영상과 전사문을 기록에 붙인다. 작성 도구의 강의 녹화 버튼에서 시작한다. 녹화창을 접어 두고 본문에 메모를 쓸 수 있다.

## 현재 동작

화면 공유 영상과 마이크 음성을 함께 녹화한다. 내 얼굴을 켜면 웹캠 영상을 오른쪽 아래에 합성한다. 화면 소리는 선택 사항이며 공유 대상과 브라우저가 제공하는 경우에만 포함된다. 출력 화면은 1280×720이다.

일시 정지, 계속 녹화, 종료를 지원한다. 종료 후 기록에 넣기를 누르면 영상 파일과 시간 표시가 붙은 전사문이 들어간다. 원래 작성 중인 기록을 중간에 저장했어도 그 기록을 찾아 첨부한다. 현재 작성칸에 들어간 영상은 기록 저장 버튼으로 저장을 마친다. 로컬 폴더 또는 드라이브 연결 시 기존 기록 동기화 경로를 사용한다. 영상 저장 버튼은 파일을 직접 내려받는다.

한국어 전사는 브라우저 음성 인식 기능을 사용한다. 인식된 문장을 수정할 수 있다. 브라우저 제공 업체의 음성 처리 서버를 사용할 수 있으며, 지원되지 않거나 연결이 끊기면 전사가 빠질 수 있다. 전사 오류가 영상 녹화를 멈추지는 않는다. 녹화 종료 후 음성을 다시 전사하는 별도 AI 엔진은 아직 구현하지 않았다.

녹화 조각은 1초 간격으로 이 브라우저의 IndexedDB에 저장한다. 창을 닫았다가 강의 녹화를 다시 열면 저장된 이전 녹화를 복구할 수 있다. 마지막 미저장 조각은 복구되지 않을 수 있다. 브라우저 데이터 삭제나 저장 장치 고장까지 보장하는 백업은 아니다. 임시 저장 공간이 부족해지면 녹화를 종료하고 내려받기 경로를 제공한다.

## 검증 범위

Edge에서 합성 화면, 합성 웹캠, 오실레이터 음성으로 실제 MediaRecorder를 실행했다. 합성 화면의 색상, 얼굴 위치, 시간 표시 전사, 일시 정지, 트랙 종료, 저장 조각 복구, 영상 첨부와 녹음된 음성의 디코딩을 확인했다. 전사 엔진은 시험 대역을 사용했으므로 실제 한국어 인식 정확도를 측정한 결과는 아니다.

실제 카메라와 마이크, 수업 한 회 분량의 녹화, 브라우저가 배경으로 이동한 상황, 시스템 음성 포함, 연결된 로컬 폴더와 드라이브의 대용량 업로드는 실제 장비로 추가 확인해야 한다.

## 관련 코드

녹화와 복구는 lecture-recorder.js, 작성 기록 연결은 index.html, 브라우저 검증은 docs/점검도구/편집미디어.mjs에 있다.
