# 의견 받기

앱 오른쪽 아래 💬 로 들어온 **질문 · 개선 의견 · 오류** 를 구글 시트 한 장에 모읍니다.

이 앱은 서버가 없습니다. 그래서 받는 자리도 서버가 아니라, 시트에 붙인
**구글 앱스 스크립트 웹 앱** 하나입니다. 앱은 그 주소로 글을 한 통 던지고,
스크립트가 시트에 한 줄을 더합니다.

## 붙이는 법

1. 의견을 모을 구글 시트를 엽니다.
2. `확장 프로그램` → `Apps Script`
3. [`Code.gs`](Code.gs) 내용을 그대로 붙여 넣고 저장합니다.
4. `배포` → `새 배포` → 유형 **웹 앱**
   - 실행 계정 · **나**
   - 액세스 권한 · **모든 사용자** ← 이걸 안 바꾸면 로그인한 사람만 보낼 수 있습니다
5. 나온 `…/exec` 주소를 앱의 `설정` → `💬 의견 받기` 칸에 붙여 넣고 `주소 저장`.
6. `시험 삼아 한 통 보내기` 를 눌러 시트에 한 줄이 늘어나는지 봅니다.

모두에게 적용하려면 `index.html` 의 `FEEDBACK_URL` 에도 같은 주소를 적습니다.
설정 칸에 넣은 주소는 **그 기기에만** 남습니다.

## 머리줄(헤더)은 손댈 것이 없습니다

첫 의견이 들어오는 순간 스크립트가 `의견` 시트를 만들고 머리줄 열여섯 칸을 세웁니다.
굵게 · 첫 줄 고정 · 「내용」 칸 너비와 줄바꿈까지 같이 맞춥니다. 미리 만들어 둘 필요가 없습니다.

머리줄을 잘못 지웠거나 시트를 새로 팠을 때만 손으로 한 번 세우면 됩니다.
시트를 열면 위쪽에 **`의견 받기`** 메뉴가 붙어 있습니다 → **`머리줄 세우기`**.
1행만 다시 쓰고, 아래에 쌓인 의견은 건드리지 않습니다.

> 메뉴가 안 보이면 시트를 한 번 새로고침하세요. `onOpen` 은 시트를 열 때 걸립니다.

> 코드를 고친 뒤에는 `새 배포` 를 다시 해야 바뀐 것이 적용됩니다.
> 같은 주소를 그대로 쓰려면 `배포 관리` → 연필 → 버전 `새 버전` → `배포`.

## 캡처 한 장

오류는 말보다 그림이 빠릅니다. 💬 창에서 세 갈래로 붙일 수 있습니다.

- **붙여넣기** `Ctrl+V` — 윈도우 캡처 도구로 잘라 바로 붙이는 길. 제일 많이 씁니다
- **끌어다 놓기** — 이미 파일로 저장해 둔 경우
- **그림 고르기** — 위 둘이 막힌 기기에서

보내기 전에 긴 쪽 1600px 으로 줄입니다. PNG 로 담고, 1.2MB 를 넘으면 JPEG 로 바꿉니다.
글자가 든 화면이 많아 PNG 를 먼저 봅니다.

받은 그림은 **시트가 든 폴더 안** 의 `의견 캡처` 폴더에 들어갑니다.
파일 이름은 `날짜_접수번호_원래이름` 이고, 시트의 `캡처` 칸에 그 주소가 찍힙니다.

> **공유 설정은 건드리지 않습니다.** 캡처에는 보낸 사람의 화면이 찍혀 있습니다.
> 시트 주인만 열 수 있게 두는 것이 맞습니다.

스크립트는 이 웹 앱을 만든 사람의 계정으로 돕니다. 그래서 보내는 사람이
드라이브에 로그인해 있지 않아도, 폴더에 아무 권한이 없어도 그림이 들어갑니다.

### 옛 판 스크립트를 쓰고 있으면

캡처를 받을 수 있는 판인지는 앱이 **답을 읽어서 확인합니다.**
옛 판이면 「글은 보냈습니다 · 다만 캡처는 저장되지 않았습니다」 라고 그대로 말하고,
보낸 목록에 「캡처 빠짐」 을 남깁니다. 조용히 버리지 않습니다.

## 시트에 쌓이는 것

| 열 | 무엇 |
|---|---|
| 접수시각 | 스크립트가 받은 때 |
| 종류 | 질문 · 개선 의견 · 오류 |
| 내용 | 사람이 적은 글 |
| 캡처 | 드라이브에 담은 그림 주소 (안 붙였으면 빈 칸) |
| 답 받을 곳 | 안 적어도 됩니다 |
| 지금 화면 | 어느 화면에서 보냈는지 (목록 · 기록 편집 · 집중 모드…) |
| 창 크기 · 드라이브 · 기록 수 · 쪽 · 브라우저 · 언어 · 앱 갱신일 | 고칠 자리를 좁히는 데 씁니다 |
| 보낸 기기 | 이름 없는 번호 하나. 같은 사람이 이어 보낸 것을 묶어 보려는 것뿐입니다 |
| 접수번호 | 같은 글이 두 번 들어왔는지 가려낼 때 |
| 상태 · 처리 메모 | 받은 뒤에 손으로 채우는 칸 |

**기록의 제목 · 내용 · 사진은 보내지 않습니다.** 사람이 적은 글과 화면 정보만 갑니다.

## 못 보냈을 때

주소가 없거나 인터넷이 끊겨 있으면, 적은 글을 그 기기에 남겨 둡니다.
다음에 앱을 열 때 조용히 다시 던집니다. 사람이 다시 적을 일은 없습니다.
보낸 목록은 💬 창 아래쪽 「이 기기에서 보낸 의견」 에서 볼 수 있습니다.

## 왜 앱스 스크립트인가

- 구글 시트 API 를 앱에서 직접 부르려면 시트를 쓸 권한이 필요합니다.
  이 앱의 권한은 `drive.file` 이라 **앱이 만들지 않은 파일** 에는 손이 닿지 않습니다.
- 앱스 스크립트 웹 앱은 **만든 사람의 계정으로** 실행됩니다.
  보내는 사람은 시트에 아무 권한이 없어도 되고, 로그인하지 않아도 됩니다.
- 앱에는 열쇠(키·토큰)를 심지 않습니다. 심으면 소스가 공개된 순간 같이 공개됩니다.
