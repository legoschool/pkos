24개 장면은 독립된 HTML 페이지 24개가 아닌 사용자 흐름이다. 기존 구현 화면은 공통 디자인을 적용하고, 목업에만 있던 기능의 완성을 의미하지 않도록 구분했다.

## 바뀐 동작

목록 제목은 본문을 목록 안에 펼치지 않고 읽기 패널을 연다. PC는 탐색 220px, 목록 280px, 오른쪽 문서로 구성한다. 문서의 편집 버튼이 기존 편집기를 연다. 사진·캡처·파일·링크·필기·녹음·강의 녹화는 삽입 메뉴에 모았으며 원래 버튼과 이벤트를 유지했다.

지식맵 도구는 캔버스를 덮지 않는 상단 영역으로 이동했다. 선택한 기준은 배경과 체크 표시로 구분한다. 연결이 많은 기록은 사용자 요청에 따라 6·8·10각 별을 유지한다. 직접 연결은 실선, 자동 연결은 점선이다.

## 검증

`node docs/점검도구/PKOS_NEW_화면.mjs http://127.0.0.1:8137/`

시험 브라우저에만 만든 기록 12개로 실행. 사용자 폴더와 기록을 바꾸지 않았다. 1440/768/390px 기본 화면, 읽기·편집 전환, 지식맵 다중 기준, 검색 범위, 설정 7개 탭, 어두운 색상 토큰을 확인했다. 이 폴더의 PNG는 구현 화면을 캡처한 것이며 기록 내용은 시험 데이터다.

실행 주소 8791은 확인 시 서버가 실행되지 않았다. 시험 서버 8137에서 확인했고, 사용자의 원본 연결 경로를 임의 지정해 8791 서버를 시작하지 않았다.
