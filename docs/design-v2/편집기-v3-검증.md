# 편집기 v3 수정 및 확인

2026-09-20. 제목·태그·본문 이름표를 표시하고 제목과 태그 입력란 테두리를 복구했다. 본문 기본 크기는 18px, 태그 입력은 16px, 저장 위치는 15px이다. 사용자 글자 배율은 유지한다.

도구줄의 sticky 배치를 해제하고 본문과 12px 간격을 뒀다. 빈 본문 안내는 첫 문단에 붙여 커서와 같은 줄에 놓았다. 편집 중인 기록에도 저장 위치를 표시한다.

마크다운 입력은 굵게, 기울임, 취소선, 인라인 코드를 즉시 변환한다. 줄 시작의 #, ##, ###, -, 1., >, [ ] 뒤 스페이스는 제목, 목록, 인용, 할 일로 바꾼다. 기존 서식 도구를 유지한다. 한글 조합 중에는 변환하지 않는다. 모든 마크다운 문법을 구현한 것은 아니다.

검사: `node docs/점검도구/PKOS_NEW_화면.mjs http://127.0.0.1:8137`

별도 임시 브라우저에서 실제 문자 입력, 서식 종료 후 일반 글 입력, 저장 후 재편집, 제목 단계 복원, 화면 폭 1440·768·390px 겹침과 가로 넘침을 검사했다. 한글 조합 이벤트 검사는 자동화한 모의 이벤트다. Windows 실제 한글 입력기의 수동 검사를 대체하지 않는다.

기존 `기록저장.mjs`는 사라진 입력 요소에 값을 지정하다 중단됐다. 이 검사 전체가 통과했다고 보고하지 않는다. 이번 저장 검사는 위 화면 검사에 포함되어 있다.

사용자의 파일이나 연결 폴더는 변경하지 않았다. 검사 당시 8791 서비스는 실행되지 않았고 8137 정적 검사 서버만 실행됐다. 실제 폴더 저장 및 원래 서비스 재접속은 이번 검사에 포함하지 않았다.
