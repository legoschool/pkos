# 폴더와 미리보기

설정의 저장 위치에서 PC 폴더를 고릅니다. Google Drive 데스크톱에 연결된 폴더를 고르면 앱을 닫아도 Drive가 파일을 동기화합니다. PC가 꺼져 있거나 절전 상태면 동기화가 멈춥니다. PKOS 기록 목록은 앱이 열려 있을 때 갱신됩니다.

앱은 2초마다 변경을 확인합니다. 파일 수와 Drive 다운로드 속도에 따라 반영 시간이 늘어납니다. 창으로 끌어 놓은 파일은 선택한 폴더의 받은 파일에 저장됩니다. 이름이 겹치면 번호를 붙입니다. 같은 작업에서 넣은 사진과 영상은 한 기록으로 묶습니다.

폴더에서 삭제한 기록은 목록에서 숨기고 파일이 돌아오면 다시 표시합니다. 앱과 폴더에서 같은 글을 수정한 경우 외부 원본을 .pkos-conflicts에 보관한 뒤 앱의 글을 저장합니다. 앱 관리 색인과 .git, .obsidian, .trash, .pkos-conflicts는 일반 자료로 가져오지 않습니다.

HTML은 별도 미리보기 안에서 실행됩니다. 상대 경로 이미지와 스타일 파일을 읽습니다. 외부 링크는 사이트가 삽입을 허용해야 표시됩니다. 차단된 사이트는 원본 열기를 누릅니다. 영상은 브라우저가 지원하는 형식이어야 재생됩니다.

점검: 미리보기동기화.mjs는 격리된 브라우저 시험 폴더에서 추가·수정·삭제·복원, 파일 205개, HTML, URL, 사진과 영상 슬라이드를 확인합니다. 실제 개인 폴더와 Google Drive 클라우드 동기화 완료 여부를 검증하는 시험은 아닙니다.
