# PKOS를 만든 과정

PKOS는 기록을 직접 쓰면서 발견한 불편을 고치는 방식으로 개발했습니다. 화면과 실제 파일을 함께 확인했습니다. 반복했습니다. 초기에는 기록과 Drive 저장을 만들었고, 이후 로컬 폴더 연결과 문서 미리보기, 사진과 녹음, 관계망으로 작업을 넓혔습니다.

사용자가 보낸 화면에서는 중복 메뉴, 빈 사진 편집창, 남아 있는 태그, 색감 변경에 따라 달라지는 글씨가 드러났습니다. 이 문제들을 편집·탐색·설정·파일 처리로 나눠 수정하고 독립 데이터로 검사했습니다. 기록을 남겼습니다. 현재 반영 여부와 검사 범위는 [현재 상태](현재상태.md)에 모았습니다.

|---|---|

| [변경 내역 · 합친 기록](변경내역.md) | 초기 구현부터 지금까지의 이력 한 벌 (2026-09-17 에 하나로 합침) |
| [변경 내역](변경내역.md) | 이전 기능 변경 이력 |
| [현재 상태](현재상태.md) | 현재 제공하는 기능과 보류 항목 |
| [작업 이어가기](작업이어가기.md) | 다음 수정의 기준 |

이전 일지에는 이후 제거한 기능과 당시 배포 대기 상태도 남아 있습니다. 이력입니다. 현재 제공 여부는 현재 상태 문서를 기준으로 판단합니다.
