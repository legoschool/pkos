# PKOS 인수인계서

작성일: 2026-09-12

## 실행과 배포

공개 앱은 https://legoschool.github.io/pkos/ 이다. PC 연결 앱은 http://127.0.0.1:8788/?localBridge=1 이다. GitHub Pages에서는 Python 프로그램을 실행하지 않으므로 PC 전용 폴더 이름 변경과 백그라운드 연결은 PC 앱에서 사용한다.

저장소의 main 브랜치에 반영하면 GitHub Actions가 공개 사이트 파일만 배포한다. 개인 기록 목록과 실행 로그는 포함하지 않는다.

## 이번 기능

외부 문서 파일을 넣을 때 저장 이름을 입력한다. 폴더 구조에서 파일명을 바꾸면 실제 파일명과 첨부 경로를 갱신한다. 확장자는 유지한다.

태그와 하위 폴더 이름을 우클릭 메뉴로 바꾼다. 태그와 같은 이름의 최상위 하위 폴더가 있으면 함께 바꾼다. 이름 충돌은 거부한다. 실패하면 변경을 되돌린다.

목록과 지식맵에서 기록을 폴더로 끌어 복사·이동을 고른다. 기록과 첨부를 함께 처리하며 파일 검증과 색인 저장 후 원본을 정리한다. 공유 중이거나 작업 도중 바뀐 원본은 남긴다.

문서·미디어 미리보기, 녹음 처리, 로컬 저장의 기존 보완 사항을 함께 반영했다. 이번 배포 검증을 전체 환경의 모든 기능 검증으로 표현하지 않는다.

## 보존 원칙

사용자의 기존 기록은 시험 데이터로 사용하지 않는다. 블로그 기록의 추가 정리는 사용자에게 남겼다. 사용자가 직접 선택한 작업 외에는 원본 파일을 일괄 변경하지 않는다.

## 점검과 남은 범위

파일 이름 변경과 태그·폴더 변경은 임시 실제 폴더 및 Edge 화면으로 점검한다. 이동·복사는 분리된 브라우저 저장소에서 실제 마우스 드래그와 파일 바이트를 확인한다. 렌더링 엔진과 인증 등 외부 서비스 전체를 새로 검증한 것은 아니다.

PC 자동 실행은 local-service/start.ps1과 startup.vbs를 사용한다. PC가 꺼지거나 절전 중이면 처리가 멈춘다. 설치 환경의 폴더 경로를 확인한다.

주요 파일: index.html, view.html, document-preview.js, pdf-reader.js, local-bridge.js, local-service/server.py, local-service/rename_ops.py.

이번 커밋은 현재 파일과 배포본을 정리한다. 과거 Git 이력 재작성은 별도의 범위 확인이 필요하다.

## 마무리 확인 (2026-09-12)

저장·중단 복구·동시 쓰기·이름 변경 검사 23개를 함께 실행해 통과했다. 격리된 시험 폴더를 사용했다. PC 연결 상태도 ready로 확인했다.

기능 커밋 c763c43의 공개 배포가 성공했다. 현재 추적 중인 작성 파일에서 제거 대상 참고 표현이 발견되지 않았다. 과거 커밋 이력은 재작성하지 않았다.

미리보기 범위도 확인했다. PDF는 전용 뷰어를 사용하고 DOCX·XLSX·PPTX·HWPX·ODT·ODS·ODP는 텍스트를 추출한다. 원본 문서의 배치와 글꼴을 그대로 재현하지 않는다. ZIP은 파일 목록을 표시한다. 구형 DOC·XLS·PPT·HWP의 본문 미리보기는 지원하지 않는다. 해당 파일도 저장할 수 있다.

추가 구현은 여기서 멈춘다. 블로그 기록 정리는 사용자에게 남긴다. 다음 작업자는 다중 파일 변경 도중 전원이 끊긴 상황의 복구와 구형 문서 미리보기를 미완료 항목으로 이어받는다.

## 문서 이미지 미리보기 보강

DOCX 본문과 PPTX 슬라이드에 포함된 PNG·JPEG·GIF·WebP 이미지를 텍스트 아래에 표시한다. 이미지가 여러 장이면 이전·다음 버튼으로 넘긴다. 편집창과 전체 보기에서 사용할 수 있다.

문서 내부 이미지 연결만 읽는다. 외부 이미지 주소와 지원하지 않는 형식은 읽지 않으며 본문은 계속 표시한다. 이미지 한 장 4MiB, 문서당 이미지 데이터 8MiB, 표시 항목 48개로 제한한다. 한도를 넘긴 이미지는 생략 안내를 표시한다. 본문 검색에서는 이미지 데이터를 읽지 않는다.

격리 브라우저의 이미지 검사 11개와 기존 문서 미리보기·긴 본문 검색 검사 20개가 통과했다. 시험 문서의 저장 전후 바이트가 일치했고 재실행 후 검색도 확인했다. 사용자 문서를 수정하지 않았다.

원본의 글꼴·배치·도형 효과와 구형 문서 형식은 아직 재현하지 못한다. DOCX 머리글·바닥글 이미지, XLSX·HWPX·OpenDocument 내부 이미지는 이번 범위에 포함하지 않았다.
