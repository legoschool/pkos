# PKOS 전체 사용 흐름 점검

상태: 로컬 수정과 검증 완료. 2026-09-14 사용자의 커밋·배포 승인을 받아 배포 절차를 진행한다.

별도 Edge와 임시 기록 폴더에서 앱을 실행했다. 개인 기록은 바꾸지 않았다. 현재 사용자 탭의 컴퓨터 제어는 Windows helper 초기화 오류로 연결하지 못했다. 브라우저 자동 조작과 화면 캡처로 점검했다.

## 발견과 수정

390픽셀 모바일 작성 화면에서 사진·녹음·강의 녹화 버튼이 도구 상자 오른쪽 밖으로 뻗었다. 모바일 버튼 그룹을 상자 안에서 줄바꿈하도록 수정했다. 수정 전후 화면과 각 버튼의 경계를 확인했다.

예전 검사에는 이전 목록 접기 버튼 위치, 삭제한 미정리함 메뉴, 받은 파일 폴더 저장 경로, 이전 HWP 시험 문구가 남아 있었다. 현재 동작에 맞춰 보완했다. 뷰어가 작성창을 가린 상태에서 숨은 버튼을 누르던 검사도 고쳤다. 모바일 펼치기 버튼은 실제 클릭 지점에서 가려지지 않는지 확인한다.

문서 시험 파일의 원본 바이트는 바뀌지 않았다. HWP는 본문 텍스트를 보여 주며 쪽 배치를 재현하지 않는다. OCR은 실제 엔진으로 정자체 시험 문장을 읽었다. 실제 손글씨 정확도는 이번 결과로 판단할 수 없다.

## 다음 확인

실제 장비의 강의 녹화를 먼저 확인하는 편이 좋다. 마이크 시험 녹음을 재생한 뒤 짧은 강의를 녹화하고 기록에 저장한다. 앱을 닫았다 다시 열어 영상·메모·전사문이 함께 남는지 확인한다. 짧은 녹화가 통과한 뒤 수업 한 회 분량으로 늘린다.

실제 마이크·카메라, 긴 녹화와 배경 탭, 한국어 전사 정확도, Google Drive 로그인·대용량 업로드, 여러 기기 동시 편집은 미검증이다. 실제 저장 폴더의 사본으로 복원 시험도 남아 있다.
