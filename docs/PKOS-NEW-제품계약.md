# PKOS NEW 제품 계약

PKOS NEW는 사용자가 소유한 파일을 기준으로 삼는다. 앱 화면이나 색인은 원본을 대신하지 않는다.

## 저장 기준

Markdown 본문과 첨부 원본은 사용자가 고른 폴더에 둔다. 브라우저 초안은 저장 실패 때 복구하는 임시 사본이다. 화면에 저장 완료가 떠도 디스크 쓰기 결과가 확인되지 않았다면 완료로 취급하지 않는다.

파일명과 경로는 바뀔 수 있다. 기존 `local:` 식별값은 읽되, 새 기능은 경로만으로 같은 문서라고 단정하지 않는다. 동시 수정이 생기면 한쪽을 덮어쓰지 않고 두 사본을 남긴다.

삭제와 일시 누락은 다르다. Drive Desktop이 아직 내려받지 않은 파일, 권한이 끊긴 폴더, 잠깐 읽지 못한 파일을 삭제로 전파하지 않는다.

## 실행 모드

브라우저 모드는 설치 없이 열린다. 브라우저 저장소와 사용자가 고른 폴더를 쓴다.

PC 연결 모드는 `local-service/server.py`가 지정한 폴더만 읽는다. 서버는 127.0.0.1에서만 열고, 루트 밖 경로를 거부한다. `start-pkos-new.ps1`은 기본값으로 개인 기록 대신 `%LOCALAPPDATA%\PKOS_NEW\시험 기록`을 연결한다.

Google Drive 모드는 실제 계정 권한과 리비전을 확인한 뒤 완료로 판정한다. 모의 Drive 검사 통과는 실제 계정 왕복을 뜻하지 않는다.

## 오류와 개인정보

오류 표시는 원인, 보존된 자료, 다음 동작을 함께 적는다. 저장 실패 뒤에는 초안과 원본을 지우지 않는다.

학생 이름, 학번, 사진, 음성을 서버에 모으는 기능을 기본값으로 두지 않는다. API 키는 HTML과 JavaScript에 넣지 않는다. 공개 공유본을 만들 때는 절대 경로와 비공개 첨부가 포함됐는지 먼저 확인한다.

## 완료 판정

로컬 구현, 격리 폴더 검사, 실제 폴더 검사, Google 계정 검사, 휴대폰 검사, 공개 배포를 따로 기록한다. 앞 단계가 통과해도 뒤 단계를 자동으로 완료 처리하지 않는다.
