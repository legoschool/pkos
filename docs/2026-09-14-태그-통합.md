# 기록 유형과 태그 통합

작성 화면에서 유형과 태그가 따로 움직여 선택 상태와 미리보기가 어긋났다. 분류를 태그 하나로 합쳤다.

## 변경

- 연수, 아이디어, 자료를 일반 태그와 같은 목록에 저장한다. 여러 개를 함께 선택하고 모두 해제할 수 있다.
- 새 기록은 태그 미선택으로 시작한다. 설정의 태그 탭에서 빠른 선택 태그를 편집한다.
- 이전 기록의 유형은 해당 이름의 태그로 읽는다. 중복을 제거하고, 다시 저장할 때 Markdown에는 tags만 쓴다. 이전 type 필드는 읽기 호환용으로만 처리한다.
- 목록, 미리보기, 검색과 지식맵은 같은 태그를 사용한다. 파일 이름에는 첫 번째 태그를 반영하고 전체 태그는 기록의 메타데이터에 저장한다.
- 기존 원본 파일을 일괄 개명하거나 덮어쓰지 않는다. 기록을 수정해 저장할 때 새 규칙을 적용한다.

## 검증

격리된 임시 폴더에서 브라우저로 여러 태그 선택, 태그 삭제, 파일명 반영, 저장 후 재접속을 검사했다. 이전 유형에서 옮겨 온 태그도 삭제 후 재접속했을 때 되살아나지 않았다. 카드와 모바일 배치 검사도 통과했다.

PC 연결 검사는 저장 규칙에 따라 이름이 바뀐 첨부를 허용하고, 파일 내용 BRIDGE-ORIGINAL까지 확인하도록 보강했다.
