## 외부 파일과 저장 규칙

외부 파일은 선택한 위치로 가져오며 원래 가져온 위치의 파일을 고치지 않습니다. 문서 이름은 저장 전에 확인합니다. 원본은 보존합니다. 새 저장 규칙에서는 날짜 토큰을 제거하고, 가져온 문서의 날짜 접두어는 이름 제안에서 뺍니다. 같은 이름이 있으면 충돌을 피하며 기존 파일 전체를 다시 이름 붙이지 않습니다.

폴더 구성과 파일 이름 설정에 따라 새 기록을 정리합니다. 내용으로 폴더를 추측하는 기능은 없습니다. 규칙만 적용합니다. PC 연결 서비스의 ZIP 해제는 원본 ZIP을 남기고 폴더 구조를 보존하며 경로 이탈과 이름 충돌을 검사합니다. 공개 웹만 사용하는 Drive 경로에 같은 ZIP 처리를 보장하지 않습니다.

PC 로컬 연결과 Google Drive 연결은 저장 경로가 다릅니다. PC 서비스는 웹 화면이 닫혀 있어도 실행 중인 PC에서 폴더를 확인할 수 있습니다. PC가 필요합니다. Drive 데스크톱 프로그램의 파일 동기화와 웹앱 목록 갱신도 구분합니다.
