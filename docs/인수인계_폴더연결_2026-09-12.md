# 폴더 연결 수정 인수인계

2026-09-12, PKOS 개인지식운영체계.

폴더 이름을 바꿀 때 다른 폴더의 Markdown 문서가 옛 경로를 계속 가리키던 오류를 수정했다. 파일명 변경이 다른 경로의 같은 이름까지 바꾸던 오류도 수정했다. 문서 위치에서 실제 대상 경로를 계산하고 변경 대상에 해당하는 링크만 바꾼다.

일반 링크와 이미지 링크, 참조형 링크, HTML src·href, 머리말의 local 첨부 식별값을 처리한다. 폴더 안에서 경로 관계가 그대로인 링크는 원문을 유지한다. 외부 웹 주소와 코드·주석 속 예시, 들여쓴 코드는 바꾸지 않는다. 인코딩된 파일명과 쿼리·문서 내 위치를 유지한다.

색인에 등록된 로컬 Markdown을 점검한다. 폴더 밖 문서의 변경도 기존 이름 변경 복구 기록에 포함한다. 강제 종료 후 되돌릴 때 문서 링크도 복구한다. 기록되지 않은 파일 형식 내부 링크나 모든 형식의 연결을 지원한다고 판정한 것은 아니다.

저장·복구 회귀 검사 42개, 실제 PC 임시 폴더 화면 검사 10개가 통과했다. 폴더를 연속 변경하고 재실행한 뒤 외부 문서 링크와 DOCX 미리보기를 확인했다. 변경 전 실패하던 두 회귀 사례가 수정 후 통과했다. 개인 원본은 시험에 사용하지 않았다.

주요 파일은 local-service/markdown_paths.py와 local-service/rename_ops.py다. 검사는 test_markdown_paths.py, test_rename.py, test_rename_recovery.py, check_rename_ui.py와 docs/점검도구/태그폴더이름.mjs에 있다.
