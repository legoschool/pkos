# 구형 PPT 미리보기 인수인계

2026-09-12, PKOS 개인지식운영체계.

PC 연결 앱에서 구형 PPT를 첨부하고 전체 보기 또는 편집창의 «슬라이드 미리보기 만들기»를 누른다. 설치된 PowerPoint로 PDF 사본을 만들고 기존 PDF 뷰어로 표시한다. PowerPoint를 사용 중이면 변환을 시작하지 않으며 다른 작업의 프레젠테이션을 닫지 않는다.

원본은 비공개 실행 폴더에 복사한 뒤 읽기 전용 사본으로 열고 매크로 비활성화를 요청한다. PDF는 원본과 별도 경로에 저장한다. 기존 출력은 덮어쓰지 않으며 원본 변경을 감지하면 캐시를 사용하지 않는다. 복사본의 변환 전후 해시도 확인한다. 공개 웹사이트만으로는 PC의 PowerPoint를 실행할 수 없다.

작업은 별도 프로세스로 실행한다. 앱 화면은 상태를 확인하다가 PDF가 준비되면 표시한다. 변환 중 뷰어를 닫아도 변환기는 작업을 마치고 자신이 연 프레젠테이션을 닫는다. 3분 안에 끝나지 않으면 앱은 다시 확인하라는 안내를 표시한다. 사용자 Office 작업을 강제로 종료하지 않는다.

같은 파일의 완료된 미리보기를 재사용한다. 한 번에 변환 하나를 실행하고 현재 서버 실행에서 최대 12개 작업을 보관한다. 원본 크기는 128MB까지 받는다. 재시작 전 실행에서 남은 캐시 폴더를 일괄 정리하는 기능은 아직 없다. 실행 중 작업을 잘못 지우지 않도록 이 부분은 후속 관리 과제로 남긴다.

새로 만든 두 장짜리 구형 PPT로 화면 검사 7개가 통과했다. 텍스트·파란 도형 렌더링, 다음·이전 슬라이드, 캐시 재사용과 원본 바이트 일치를 확인했다. 저장·복구·미리보기 작업 관리 검사 48개도 통과했다. 기존 Word 프로세스는 종료하지 않았다. 개인 원본은 시험에 사용하지 않았다.

변환기는 PPS·PPTX·ODP도 받을 수 있도록 구성했지만 이번 실제 파일 검증은 PPT에 한정했다. DOC·XLS·HWP의 본문 미리보기, PPT 본문을 앱 전체 검색에 넣는 작업, 모든 슬라이드 효과의 재현은 완료하지 않았다.

주요 파일: local-service/presentation_preview.py, local-service/preview_powerpoint.ps1, local-service/server.py, index.html. 검사는 local-service/check_presentation_ui.py와 docs/점검도구/구형PPT미리보기.mjs로 실행한다. 시험 파일 생성기는 local-service/create_presentation_fixture.ps1이다.

변환 방식은 Microsoft의 [Presentations.Open 문서](https://learn.microsoft.com/en-us/office/vba/api/powerpoint.presentations.open), [SaveAs 문서](https://learn.microsoft.com/en-us/office/vba/api/powerpoint.presentation.saveas), [AutomationSecurity 문서](https://learn.microsoft.com/en-us/office/vba/api/powerpoint.application.automationsecurity)를 확인했다.
