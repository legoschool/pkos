# PKOS 개인지식운영체계

PKOS는 수업 자료, 연수 기록, 사진, 녹음과 생각을 사용자의 폴더에 쌓고 다시 찾아 쓰는 기록장입니다. 기록이 출발점입니다. 파일을 보관하면서 작성 당시의 질문과 맥락도 남기고, 관계망과 지식맵에서 기록 사이의 연결을 찾습니다.

[PKOS 열기](https://legoschool.github.io/pkos/) · [설치와 연결](SETUP.md) · [개발 배경](docs/개발배경.md) · [현재 기능과 변경 기록](docs/현재상태.md)

## 왜 만들었나

교사의 경험은 문서, 사진첩, 드라이브와 메신저에 흩어집니다. 자료가 있어도 어디에 썼고 무엇을 배웠는지 찾기 어렵습니다. 원본은 남깁니다. PKOS는 파일 옆에 생각을 적고, 관련 기록을 이어서 다음 수업과 작업에 다시 쓰기 위해 만들었습니다.

AI가 만든 결과를 모으는 데서 멈추지 않고 사용자가 겪은 일과 판단을 축적하려는 목적도 있습니다. 도구를 바꾸더라도 기록을 꺼낼 수 있도록 Markdown 문서와 첨부 파일을 저장합니다. 사용자가 소유합니다.

## 지금 쓰는 방식

앱을 열면 기록창에서 시작합니다. 제목과 본문을 적고 사진이나 파일을 붙여 저장합니다. 목록은 접어 둡니다. 기록 제목을 누르면 내용이 아래로 펼쳐지고, PKOS 제목을 누르면 전체 자료를 카드로 볼 수 있습니다.

PC에서는 로컬 폴더를 연결하거나 PC 연결 서비스를 사용합니다. 휴대폰에서는 Google 로그인 후 같은 Drive 폴더를 연결하는 방식입니다. 저장 경로가 다릅니다. GitHub Pages는 앱을 제공하며 개인 기록을 저장하는 서버가 아닙니다. PC 연결 서비스와 Drive 데스크톱 동기화는 PC가 실행 중이어야 작동합니다. 휴대폰 웹 앱을 열어 둔 채로도 PC에서 쓴 기록이 따라옵니다. 화면이 보이는 동안 15초마다 Drive 색인의 수정 시각만 묻고, 바뀌었을 때만 내려받습니다.

## 주소

주소는 두 개로 고정되어 있습니다. 새 판을 올려도 바뀌지 않습니다.

| 주소 | 쓰는 곳 |
|---|---|
| https://legoschool.github.io/pkos/ | 공개 앱. 휴대폰과 다른 PC에서 엽니다 |
| http://127.0.0.1:8788/?localBridge=1 | PC 연결 앱. PC 연결 프로그램이 실행 중인 그 PC에서만 열립니다 |

지금 연 판은 설정 → 고급에서 확인합니다. 앱을 펴 둔 동안 새 판이 올라오면 편집 칸 위에 «새 판이 올라왔습니다»가 뜹니다. 새로고침하면 같은 주소에서 새 판을 씁니다. 주소 뒤에 `?deploy=…`가 붙은 옛 확인용 주소로 들어와도 앱이 꼬리를 지웁니다. 옛 주소 `legoschool.github.io/trace/`는 새 주소로 넘겨 줍니다.

## 현재 기능

| 기능 | 동작 |
|---|---|
| 기록과 첨부 | Markdown 입력, 사진, 파일, 녹음 첨부, 제목을 누르는 목록 펼치기 |
| 사진 편집 | 사진을 눌러 모자이크와 펜 표시, 되돌리기, 자르기 |
| 녹음 | 녹음 파일을 초안에 첨부, 자동 전사 문장을 넣지 않음 |
| 지식 홈 | 전체 자료 카드, 검색, 최근순과 자동 연결 수 정렬 |
| 관계망과 지식맵 | 직접 연결과 공통 단어 기반 연결, 단어 빈도와 함께 쓰인 정도 표시 |
| 폴더 탐색 | Ctrl/Cmd 개별 선택, Shift 범위 선택, 선택 폴더의 자료 함께 보기 |
| 가져오기 | 선택한 폴더와 파일명 규칙 적용, 이름 충돌 처리, PC 서비스의 ZIP 해제 |
| 모양 | 색감, 밝기, 글자 크기 5단계, 글꼴 5종을 각각 선택 |
| 사이트 추가 | 제목과 주소로 바로가기 추가, 제목 수정 |
| 설정 | 저장 위치, 가져오기, 새 기록 기본 유형, 파일 이름, 의견 보내기 |

할 일과 미정리함 메뉴, 중복 편집 버튼, 긴 도움말과 의견 연락처 입력은 화면에서 제거했습니다. 기존 기록은 보존합니다. 호환성을 위한 내부 저장 값은 일부 남아 있습니다.

## 구현 범위

관계 분석은 공통 단어와 동시 출현을 계산합니다. 의미를 이해하는 AI 분석이나 내용에 따른 자동 폴더 분류는 아직 제공하지 않습니다. 구분이 필요합니다. 사진 모자이크는 사용자가 적용하며, 브라우저 화면 캡처에는 캡처 대상 선택 절차가 남습니다.

사용자가 꾸미는 메인 화면과 선택 기록으로 사이트를 만드는 기능은 보류했습니다. 별도 기능이나 앱에서 같은 지식 베이스를 공유하는 방향으로 남겼습니다. 아직 미구현입니다. Google 로그인, 실제 휴대폰 촬영과 외부 문서 변환은 기기와 권한에 따라 별도 확인이 필요합니다.
