## 무엇을 하는 도구인가

수업과 공부, 일상에서 얻은 생각을 사진·링크와 함께 남기는 개인 기록장입니다.
기록은 내가 지정한 **구글 드라이브 폴더**에 마크다운(`.md`)과 구글 문서, 정리된 이름의 파일로 보관되고,
관련 기록을 연결해 다시 찾아볼 수 있습니다. 필요한 기록은 복사해 사용 중인 AI에 붙여넣어
생각을 검토하고 발전시키는 데 활용할 수 있습니다.

주요 기능은 `index.html` 한 파일에 모여 있고, 별도의 서버 없이 브라우저에서 바로 실행됩니다.

## 만든 이유

교사로 일하며 수업 자료와 연수 기록을 모아 왔지만, 필요할 때 다시 찾거나 당시의 생각을 떠올리기는
쉽지 않았습니다. 자료가 여러 곳에 흩어져 있었고, 기기나 계정이 바뀌면서 꺼내 보지 못하게 된 것도 있었습니다.

지식과 정보가 중요한 사회에서 정작 자신의 경험과 아이디어를 정리하고 활용할 기반은 부족하다고 느꼈습니다.
좋은 생각을 기록하지 못해 잊기도 하고, 자료만 보관한 채 다시 쓰지 못하기도 했습니다.
AI와 함께 내용을 검토하고 발전시키려 해도 먼저 기록을 찾아 모아야 했습니다.

저는 AI가 많은 일을 더 능숙하게 처리하게 될수록, 각자가 자신의 경험을 돌아보고 고유한 질문과 통찰을
키우는 일이 중요해질 것으로 생각합니다. PKOS는 그 과정을 돕기 위해 만든 개인 기록 도구입니다.
글·사진·링크를 구글 드라이브에 보관하고, 관련 기록을 연결하며, 필요한 내용을 AI에 제공해
다시 활용할 수 있도록 구성했습니다.

**PKOS라는 이름** · Personal Knowledge Operation System 의 약자로, 개인의 지식과 경험을 남기고 활용하는
체계를 뜻합니다. 기록을 찾아 읽고, 관련 내용을 연결하고, AI와 검토한 뒤 실제로 시도한 결과를 다시 남기는
과정을 돕고자 붙인 이름입니다. 컴퓨터의 운영체제를 뜻하는 말은 아닙니다. 현재의 개인지식운영체계는 그 환경을
만들어 가기 위한 도구이며, 제 수업과 공부에서 필요한 기능을 중심으로 다듬고 있습니다.

원문과 설계 결정, 개발 연혁은 [docs/개발배경.md](docs/개발배경.md) 에 있습니다.

### 이름이 바뀌어 온 과정 · PKEMS → PEER → TRACE → PKOS

만드는 동안 이름이 세 번 바뀌었습니다. **지금 이름은 PKOS 하나이며, 앞의 세 이름은 더 쓰지 않습니다.**

| 날짜 | 이름 | 무엇이 마음에 걸려 바꿨나 |
|---|---|---|
| 8/16 | **PKEMS** · Personal Knowledge Editing & Management System | 처음에는 「편집하고 관리하는 도구」로 생각했습니다. 이름이 길고, 하는 일보다 기능 목록에 가까웠습니다 |
| 8/20 | **PEER** | 기록을 함께 살피는 동료라는 뜻으로 짧게 줄였습니다. 너무 흔한 낱말이라 찾기도 설명하기도 어려웠습니다 |
| 8/21 | **TRACE** | 남은 자취라는 뜻으로 붙였고, 이때 「체계 이름(TRACE)」과 「도구 이름(구글 기록장)」을 갈라 놓았습니다. 쓸수록 하는 일이 기록을 **운영하는** 쪽으로 굳어져 뜻이 어긋났습니다 |
| 9/10 | **PKOS** · Personal Knowledge Operation System · 개인지식운영체계 | 지금 이름. 남기고 · 연결하고 · AI와 검토하고 · 다시 남기는 과정 전체를 가리킵니다 |

이름을 바꾸는 일은 화면의 글자만 바꾸는 일이 아니었습니다. 이름은 구글 드라이브의 파일 이름과
브라우저 저장 키에도 박혀 있어서, 잘못 건드리면 쓰던 사람의 기록이 통째로 「없는 것」이 됩니다.
그래서 **코드 안쪽에는 옛 이름이 일부러 남아 있습니다.**

| 일부러 남긴 옛 이름 | 왜 남겼나 |
|---|---|
| `TRACE-index.json` · `PEER-…` · `PKEMS-…` 를 찾는 부분 | 옛 이름으로 저장된 드라이브 파일을 처음 열 때 **파일 ID 는 그대로 둔 채 이름만** 새 이름으로 바꿉니다 |
| `trace.*` · `peer.*` · `pkems.*` 저장 키를 읽는 부분 | 브라우저에 남은 옛 기록을 `pkos.*` 로 이어받습니다. 옛 키는 지우지 않습니다 |
| IndexedDB 이름 `pkems` | 아직 올리지 못한 사진·파일이 이 안에 들어 있어 바꾸지 않았습니다 |

이 셋을 「이름 통일」이라며 지우면 옛 이름으로 쓰던 사람의 기록을 못 읽게 됩니다.
자세한 내용은 [docs/개발배경.md](docs/개발배경.md) 와 [docs/작업이어가기.md](docs/작업이어가기.md) 에 있습니다.

## 빠른 시작

링크를 받은 사람이 처음 한 번 하는 일입니다. (사본을 만들어 나눠 주려면 [SETUP.md](SETUP.md))

1. 기록장을 열고 **「구글 로그인」** 을 누릅니다.
   앱을 만든 사람의 설정에 따라 「Google에서 확인하지 않은 앱」 화면이 나올 수 있습니다.
   앱 이름과 요청 권한(앱이 만들거나 고른 드라이브 파일)을 확인한 뒤 **[고급] → [이동]** 으로 진행합니다.
2. **「⚙️ 설정 → 저장 위치」** 에서 **「＋ 새 폴더 만들기」** 또는 **「📂 폴더 고르기」** 로 기록을 저장할 폴더를 정합니다.
   위쪽 띠가 초록색으로 바뀌고 폴더 이름이 보이면 연결된 것입니다.
3. 제목과 내용을 쓰고, 필요하면 사진이나 링크를 넣습니다.
4. **「기록 저장」** 을 누릅니다. 카드에 「☁ 저장됨」 이 보이면 드라이브에 올라간 것입니다.
   다른 기기에서도 같은 계정·같은 폴더로 열어 보면 기록이 이어집니다.

> 작성 중인 내용은 이 브라우저에 임시 보관됩니다. 구글 드라이브에 저장하려면 「기록 저장」 을 눌러야 합니다.
> 임시 보관은 그 기기의 브라우저 안에서만 유효합니다.

## 주요 기능

### ✍️ 종이 편집기 · 글과 자료를 함께 기록하기

종이 한 장에 글을 쓰면서 사진·링크·파일을 함께 넣습니다.

- 사진·파일을 **붙여넣거나(Ctrl+V) 끌어다 놓으면 커서 자리** 에 들어갑니다
- **Enter** 로 줄을 바꾸고, 글을 고른 뒤 굵게·기울임·취소선·형광펜·코드를 입힙니다 (Ctrl+B · Ctrl+I)
- 빈 줄에서 **`/`** 를 치면 넣을 것을 고르는 메뉴가 뜹니다 (소제목·할 일·목록·표·사진·캡처·파일·링크·코드·접이식·구분선…)
- **`[[`** 를 치면 다른 기록과 연결됩니다
- 웹 주소를 붙여넣으면 **링크 카드**, 유튜브·구글 문서 주소면 **화면 안에서 재생되는 삽입** 이 됩니다
- 사진·파일·링크·표·코드·접이식은 덩어리로 서고, 손잡이(⠿)를 끌거나 ▲▼ 로 옮기고 ✕ 로 지웁니다
- 마크다운(`- [ ]` · `- ` · `1. ` · `> ` · `## ` · 표 · 코드 울타리)을 붙여넣으면 그대로 줄이 됩니다

| 종이 위의 것 | 저장되는 마크다운 |
|---|---|
| 글 · 소제목 | 문단 · `## 소제목` |
| 할 일 · 목록 | `- [ ] 할 일` · `- 항목` · `1. 항목` (Tab 으로 한 단 들여쓰기) |
| 인용 | `> 인용` · 출처 갈래가 있으면 첫 줄에 `> [!note] 💭 내 생각` 같은 콜아웃 |
| 사진 · 캡처 · 손 메모 | `![캡션](파일명)` + 드라이브 링크 주석 |
| 녹음 | 소리 파일 + 받아 적은 글 |
| 파일·영상 | `📎 [파일명](드라이브 링크)` · 영상·소리는 카드에서 바로 재생 |
| 링크 | `🔗 [설명](URL)` |
| 표 · 코드 · 접이식 · 구분선 | 파이프 표 · ```` ``` ```` · `<details>` · `---` |
| 코드 삽입 | HTML 그대로 (유튜브·구글 문서 등) |

저장 형식은 «블록 목록» 그대로입니다. 종이는 보여 주는 쪽이고, 저장 직전에 종이를 읽어 블록으로 되돌립니다.
그래서 이전 판에서 쓴 기록도 그대로 열립니다.

**양식** · `＋ 새 기록` 옆 `▾` 에 「수업 회고」·「연수 정리」 같은 양식이 있습니다. 소제목·유형·태그가 잡힌 채로 열리고,
`{날짜}`·`{요일}` 은 여는 순간의 값으로 바뀝니다. 양식은 설정에서 만들고 고칩니다.

**집중 모드** (`🎯 집중`) · 왼쪽 메뉴·목록·머리띠를 감추고 적는 칸만 남깁니다. `Esc` 로 나옵니다.

### 💭📚🤖 출처 구분하기

인용 상자에 세 가지 표시를 붙일 수 있습니다. 넣기 줄 오른쪽 끝, 또는 `/` 메뉴에 있습니다.

| 갈래 | 뜻 | 읽을 때 | 저장 |
|---|---|---|---|
| 💭 **내 생각** | 내가 해석하고 판단한 것 | 파란 상자 | `> [!note] 💭 내 생각` |
| 📚 **자료 인용** | 강사 말·책·논문·웹에서 옮긴 것. 출처 칸이 붙습니다 | 회색 상자 + 출처 | `> [!quote] 📚 자료 인용 · 출처` |
| 🤖 **AI 답변** | AI가 답한 것. 어느 AI인지 적습니다 | **접혀 있음** · 눌러야 펼쳐집니다 | `> [!ai]- 🤖 AI 답변 · ChatGPT` |

글을 쓰다가 그 줄에서 갈래 버튼을 누르면 그 줄이 그 갈래의 상자가 됩니다. 상자 오른쪽 ▾ 로 갈래를 바꾸거나
「인용 풀기」 로 되돌립니다. 옵시디언은 이 콜아웃 표기를 알아보고, `[!ai]-` 는 거기서도 접혀서 열립니다.

AI 답변을 접어 두는 이유는, 시간이 지난 뒤 AI가 한 말을 내 생각으로 착각하지 않게 하려는 것입니다.

### 💬 의견 보내기

오른쪽 아래 **💬** 를 누르면 질문 · 개선 의견 · 오류를 그 자리에서 적어 보낼 수 있습니다.
보낸 글은 만든 사람의 구글 시트 한 장에 쌓입니다.

- 함께 가는 것은 화면 정보뿐입니다 (창 크기 · 브라우저 · 지금 보던 화면)
- **기록의 제목 · 내용 · 사진은 보내지 않습니다**
- 인터넷이 끊겨 있으면 그 기기에 두었다가 다음에 열 때 다시 보냅니다

### 📥 미정리함

급하면 태그 없이, 제목 없이 저장해도 됩니다. 그런 기록은 왼쪽 메뉴의 **「📥 미정리함」** 에 모입니다.
태그를 붙이면 자동으로 빠져나가고, 태그가 있어도 나중에 손보고 싶으면 작성칸의 **「📥 나중에 정리」** 를 켜 둡니다.
카드의 ⋯ 메뉴 **「✅ 정리 끝」** 으로 뺍니다.

### 📸 캡처 · 사진 넣기

버튼을 누르면 넣는 방법을 고르는 시트가 뜹니다. 기기에 따라 선택지가 다릅니다.

| PC | 휴대폰 |
|---|---|
| 📋 클립보드에서 붙여넣기 (가장 빠름) | 🖼️ 갤러리에서 고르기 · 스크린샷·사진 |
| 🖼️ 이미지 파일에서 고르기 | 📷 카메라로 찍기 |
| 📷 웹캠으로 찍기 | 📋 클립보드에서 붙여넣기 |
| 🖥️ 화면 캡처하기 (창 공유 화면이 뜸) | |

`Win+Shift+S`(맥 `⌘⇧4`)로 캡처한 뒤 종이에 `Ctrl+V` 하면 선택 창 없이 바로 들어갑니다.
어느 쪽이든 이미지가 뜨면 드래그해서 필요한 영역만 잘라 넣을 수 있고, 「자르지 않고 원본 그대로 넣기」 를 켜 둘 수도 있습니다.
휴대폰 고화질 사진은 긴 변 2400px 로 줄여 담고, 용량이 크면 JPEG 로 바꿉니다.
화면 직접 캡처는 `https://` 또는 `localhost` 에서만 되고, 휴대폰 브라우저는 지원하지 않습니다.

### 🔲 사진 가리기

내용 칸 위의 **「🔲 사진 가리기」** 를 누르면 이 기록의 사진이 한 줄로 늘어섭니다.
사진에서 가릴 자리를 누르거나 문지르면 그 부분이 모자이크로 가려집니다.

- 원 크기 4단계. 누르기 전에 얼마나 가려질지 동그라미로 미리 보입니다
- 칸 굵기는 곱게·보통·굵게. 곱게 갈수록 원래 모습이 비쳐 보이니, 남에게 보일 사진이면 굵은 쪽이 안전합니다
- `↩ 한 번 되돌리기` · `이 사진 원래대로` · `← 이전 / 다음 →`
- 이미 드라이브에 올라간 사진도 됩니다. 저장하면 같은 파일에 덮어씁니다 (파일 이름과 주소가 그대로라 링크와 색인이 어긋나지 않습니다)
- 사진 덩어리의 **「🔲 가리기」** 로 한 장만 열 수도 있고, 공유 창의 사진 확인 화면에도 **「🔲 지금 가리기」** 가 있습니다

가린 결과는 올라가는 사진 자체에 적용됩니다. 얼굴을 자동으로 찾아 주지는 않으므로 공유 전에 사진을 확인해 주세요.
드라이브의 「버전 기록」에는 가리기 전 사진이 남을 수 있습니다. 완전히 없애려면 드라이브에서 이전 버전을 지웁니다.

### 📥 휴대폰 공유 메뉴로 담기 (안드로이드)

안드로이드에서 앱으로 설치(「홈 화면에 추가」)해 두면 공유 메뉴에 「개인지식운영체계」가 나타납니다.

사진·파일은 첨부로 들어옵니다. 쓰던 글은 지워지지 않고 그 뒤에 이어 붙습니다.

아이폰 사파리는 이 방식을 지원하지 않습니다. 주소를 복사해 붙여넣거나 사진첩에서 골라 넣습니다.
컴퓨터에서는 웹페이지 주소를 복사해 종이에 붙여넣으면 링크 카드가 됩니다.

### 🔗 연결 · 백링크 · 관계망

연결하는 방법은 두 가지이고 결과는 같습니다.

- **글을 쓰다가** · 종이에 `[[` 를 치면 기존 기록 목록이 뜹니다 (↑↓ 이동, Enter 선택). 없는 제목을 적으면 점선으로 표시되고, 누르면 그 제목으로 새 기록이 시작됩니다
- **관계망에서** · 점을 누르고 「🔗 다른 기록과 잇기」 → 상대 점을 누릅니다. 「여기서 배움」·「근거가 됨」 같은 설명을 붙일 수 있습니다

각 기록 카드 아래에 연결 줄이 붙습니다. `→` 는 내가 건 연결, `←` 는 나를 가리킨 기록(백링크)입니다.
다른 기록에서 이 기록을 연결하면, 이 기록에는 아무것도 하지 않아도 연결한 기록 목록이 함께 표시됩니다.

**🕸️ 관계망** · 점 = 기록(유형별 색, 연결이 많을수록 큼), 화살표 = 연결, 점선 = 같은 태그(기본 꺼짐).
점을 누르면 정보 창이 열려 미리보기·나가는 연결·백링크가 보이고, 거기서 연결을 만들고 끊고 기록을 엽니다.
끌어 옮기기·확대·축소가 되고 휴대폰에서도 터치로 같습니다. 여기서 만든 연결은 각 기록의 `.md` 파일 `## 연결` 항목에 저장됩니다.
앱 안의 **❔ 사용법** 버튼에 예시와 함께 설명이 있습니다.

### 👁 전체 보기 · 🔗 링크로 공유

기록 제목을 누르면 한 편이 펼쳐집니다. 위쪽 도구 모음에서 🖨️ 인쇄(PDF로 저장) · 📄 구글 문서 · 🌐 HTML 파일(설정에서 켠 경우) · 📝 `.md` · 📁 폴더 · 🔗 링크로 공유 · ✏️ 편집으로 이어집니다.
PC 3단 화면에서는 오른쪽 칸에서 열리고, 좁은 화면에서는 창으로 뜹니다.

**「🔗 링크로 공유」** 에서는 네 가지 중 하나를 고릅니다.

| | 넘어가는 것 | 어울리는 때 |
|---|---|---|
| ① 🌐 **웹 쪽으로** | 글·사진·영상·녹음이 한 쪽에. 영상과 녹음은 받는 화면에서 바로 재생 | 영상·녹음이 있을 때. 링크가 길어서(700~1,000자) 메신저에 다 들어갔는지 확인 |
| ② 🌐 **웹 페이지로** (구글 문서 게시) | 글과 사진이 한 쪽에. 고친 내용이 따라감 | 계속 고칠 글 |
| ③ 📄 **구글 문서 파일** | 구글 문서 그대로 | 문서로 넘겨야 할 때 |
| ④ 📁 **폴더 통째로** | 원본 사진·파일·`.md` 전부 | 자료를 통째로 줄 때. 「기록마다 폴더 하나」 방식일 때만 |

누르는 순간 그 기록(또는 폴더)의 드라이브 권한이 「링크가 있는 사람 · 읽기」 로 바뀌고 주소가 복사됩니다.
받는 사람은 로그인이나 앱 설치 없이 열 수 있습니다. 「공유 끄기」 로 권한을 되돌릴 수 있지만 이미 전달된 링크까지 거둘 수는 없습니다.

**공유 전 사진 확인** · 사진이 든 기록은 공유 버튼이 처음엔 눌리지 않습니다. 그 기록의 사진이 늘어서고
「확인했습니다. 남에게 보여도 되는 사진입니다」 를 체크해야 열립니다. 문제가 보이면 그 자리의 「🔲 지금 가리기」 로 가린 뒤 저장합니다.

드라이브는 HTML 파일을 웹페이지로 열어 주지 않습니다. 사람에게 보여 줄 것은 ①·② 를 씁니다.

### 📚 엮어내기 · 기록 모아 보기

목록 위 **「📚 엮어내기」** 를 누르면 고른 기록을 하나의 파일로 내려받습니다.

| 고르는 방법 | 설명 |
|---|---|
| 지금 화면 그대로 | 유형·태그·검색으로 걸러 둔 것이 후보가 됩니다 |
| 체크박스 | 그중에서 담을 것만 다시 고릅니다 |
| 연결된 기록도 함께 | `[[링크]]`·관계망·백링크로 이어진 기록을 한 단계 더 끌어옵니다 |

담기는 것 · 표지(제목·편수·기간) · 목차 · 각 편의 본문 · 유형·날짜·태그 · 연결 정보.
`.md` 는 옵시디언·깃허브에 그대로 쓰이고(연결은 `[[제목]]` 으로 살아 있습니다), `.html` 은 브라우저로 바로 읽히며
인쇄하면 장마다 페이지가 넘어가 책처럼 나옵니다. 뽑아낸 `.html` 은 앱에서 고른 색감을 그대로 입습니다.

안 쓴 조각은 자리가 빠지고, 같은 이름이 있으면 `-2`, `-3` 이 붙습니다. 사진·파일 덩어리의 제목 칸에 적은 것이 「자료 제목」 으로 들어갑니다.

### 📥 폴더에서 가져오기

앱은 색인 파일(`PKOS-index.json`)을 보고 목록을 만듭니다. 그래서 옵시디언에서 만든 노트나 드라이브에 직접 넣은 파일은
바로 목록에 나오지 않습니다. `설정 → 📥 가져오기` 에 두 가지 길이 있습니다.

- **📂 드라이브에서 파일 고르기** · 손으로 넣어 둔 파일을 구글 고르기 창에서 한 번 고릅니다. 이 앱의 권한은 앱이 만들거나 사용자가 고른 파일에만 미치므로, 한 번 고른 파일은 그 뒤로 계속 보입니다
- **폴더 훑어서 가져오기** · 연결한 폴더 아래를 10단계까지 훑어, 색인에 없는 `.md` 는 front-matter 와 본문을 읽어 되살리고 같은 폴더의 사진·첨부를 파일 이름으로 찾아 연결합니다. 글이 아닌 파일(한글·발표·PDF·사진·영상·구글 문서 등)은 하나를 기록 한 편으로 세웁니다. 넣기 전에 「사진 1,204개 · 한글 312개 …」 처럼 보여 주고 묻습니다. 거쳐 온 폴더 이름이 태그로 붙고(3겹까지), 한 번에 3000개까지 들어옵니다

원본은 옮기지도 고치지도 않습니다. 색인이 그 파일을 가리키기만 하므로, 잘못 들어와도 목록에서 지우면 됩니다.
가져온 기록에는 「📁 원본 폴더」 버튼이 붙습니다. 구글 문서·시트·슬라이드는 링크로 겁니다.

### ⏳ 임시 보관 · 📱 기기 간 동기화

- 작성 중인 내용은 1.5초마다, 그리고 탭을 벗어나거나 닫을 때 이 브라우저에 임시 보관됩니다. 제목·태그·유형·붙여 둔 사진과 파일까지 복구되고, 위쪽에 「⏳ 임시 보관 중」 띠가 뜹니다. 「기록 저장」 을 누르면 임시본은 정리됩니다
- 임시 보관은 그 기기·그 브라우저 안에서만 유효합니다. 드라이브로는 「기록 저장」 을 눌러야 올라갑니다
- 휴대폰에서 쓰고 PC 로 돌아오면(탭이 다시 보이면) 최신 목록을 다시 읽어 옵니다. 삭제도 함께 반영되고, 같은 기록을 양쪽에서 고쳤으면 나중에 고친 쪽이 남습니다
- 아직 못 올린 사진·파일은 IndexedDB 에 보관되어, 연결이 끊긴 채 써 두어도 나중에 올라갑니다
- 파일 하나당 200MB 까지. 8MB(휴대폰 2MB)씩 끊어 올리며 진행률이 표시되고, 45초 동안 진척이 없으면 받은 자리부터 다시 시도합니다. 실패가 이어지면 「⏳ 업로드 대기」 로 남았다가 「동기화」 를 누르면 다시 올라갑니다
- 로그인은 새로고침해도 유지됩니다. 구글이 주는 열쇠가 1시간짜리라 만료되면 「구글 연결이 풀렸습니다」 띠가 뜨고, 「다시 연결」 을 한 번 누르면 이어집니다

### 🧩 코드 삽입 · 🎬 영상·사진 보기

- 「코드 삽입」 에 HTML 삽입 코드를 붙여넣으면 그 자리에서 보입니다. 유튜브·Vimeo·구글 문서·드라이브 파일 주소는 붙여넣기만 해도 삽입 코드로 바뀝니다. 삽입한 코드는 격리된 틀(sandbox iframe) 안에서만 실행됩니다

### PC 연결 프로그램 (선택)

브라우저의 폴더 허용 대신, PC 에 작은 파이썬 프로그램을 띄워 두고 앱이 그 프로그램을 거쳐 폴더를 읽고 쓰는 방식입니다. `local-service/server.py` 가 `127.0.0.1:8788` 에서 기다리고, 앱은 `http://127.0.0.1:8788/?localBridge=1` 로 엽니다. 같은 컴퓨터에서만 열립니다.

- **띄우기** · `local-service/startup.vbs` 를 두 번 누릅니다. 감시 스크립트 `start.ps1` 이 파이썬을 찾아 서버를 띄우고 10초마다 살아 있는지 봅니다. 파이썬은 `C:\Python314` → `%LOCALAPPDATA%\Programs\Python\Python31x` → PATH 순으로 찾습니다.
- **켤 때마다 저절로** · `Win+R` → `shell:startup` 폴더에 `startup.vbs` 의 바로가기를 넣습니다. 이 등록은 사람이 직접 합니다.
- **기록 폴더** · `start.ps1` 맨 위 `$RecordRoot` 에 적혀 있습니다. 다른 폴더를 쓰려면 그 줄을 고칩니다.
- **안 열리면** · 구글 드라이브가 실행 중이고 G: 폴더가 열리는지 본 뒤 `local-service/runtime/supervisor.log` 를 봅니다. «Python runtime unavailable» 이면 파이썬이 없거나 다른 곳에 있는 것입니다.
- **이 방식에서만 되는 것** · 태그·폴더·파일 이름 바꾸기(우클릭). 이름을 바꾸다 프로그램이 죽어도 `runtime/rename-*.json` 기록으로 다음 실행 때 되돌리거나 이어갑니다. GitHub Pages 공개 앱은 파이썬을 못 돌리므로 안 됩니다.

`설정 → 저장 위치` 에서 **기록마다 폴더 하나** 와 **한 폴더에 전부** 중 고릅니다. 이전 판의 방식(글과 자료 분리 · 월별 폴더 · 태그가 곧 폴더)을
쓰고 있었다면 그대로 유지되고 「지금 쓰는 방식」 으로 표시됩니다. 방식을 바꾸면 앞으로 저장되는 것부터 적용되며,
이미 올라간 파일까지 옮기려면 「기존 파일도 새 방식으로 옮기기」 를 누릅니다.

기록이 많아져 색인이 256KB 를 넘으면 앱이 색인을 `PKOS-index-00.json` · `-01.json` … 조각으로 나눕니다.
이 파일들은 지우지 마세요. 하나만 지워도 그 조각에 든 기록이 목록에서 사라집니다 (원본 파일은 남으며 「폴더 훑어서 가져오기」 로 다시 담을 수 있습니다).

`설정 → 파일 이름` 에서 마크다운 외에 구글 문서 사본(기본 켜짐)과 HTML 파일(기본 꺼짐)을 함께 저장할지 정합니다.

### 고친 뒤 배포하기

```bash
git add -A && git commit -m "설명" && git push
```

`main` 에 푸시하면 GitHub Actions 가 자동 배포합니다 (1~2분). 로컬에서 시험하려면 `http://localhost:8000` 으로 띄우세요
(`file://` 로 열면 로그인·캡처·웹캠이 막힙니다). 고친 뒤에는 [docs/점검도구](docs/점검도구/README.md) 로 한 번 돌려 보세요.
코드를 이어 고칠 사람은 [docs/작업이어가기.md](docs/작업이어가기.md) 를 먼저 읽으면 됩니다.

### 기술

| | |
|---|---|
| 구성 | HTML / CSS / JavaScript 를 `index.html` 한 파일에. 빌드 도구·프레임워크 없음 (약 770KB) |
| 인증 | Google Identity Services (브라우저 토큰 방식, 클라이언트 시크릿 미사용) · 범위 `openid email drive.file` |
| 파일 고르기 | Google Picker API (폴더 지정·밖에서 만든 파일 가져오기) |
| 저장 | Google Drive REST API v3 · 글·색인은 multipart, 첨부는 resumable (PC 8MB · 휴대폰 2MB 청크, `XMLHttpRequest` 진행률, 45초 정지 감지, 429·5xx 재시도) |
| 브라우저 저장 | `localStorage` (기록·설정·삭제 기록·임시본·토큰·이메일) + `IndexedDB` (파일 본문) |
| 편집기 | contenteditable 종이 + 덩어리(figure). 저장 직전에 종이를 블록 목록으로 되돌림 |
| 캡처·웹캠 | `getDisplayMedia` · `getUserMedia` → canvas → 잘라서 재인코딩 |
| 모자이크 | 원본은 두고 가린 자리 목록만 들고 매번 다시 그림 |
| 손 메모 | `PointerEvent`(필압) → 획을 점 목록으로 → 1600×1100 으로 저장 |
| 녹음 | `MediaRecorder` + `AnalyserNode` + `SpeechRecognition`(ko-KR) |
| 공유 시트 | manifest `share_target`(POST) → 서비스 워커가 Cache Storage 에 두고 리다이렉트 |
| 관계망 | 라이브러리 없이 `<canvas>` + 힘 기반 배치 |
| 코드 삽입 | `srcdoc` + sandbox iframe (`allow-same-origin` 미부여) |
| 색인 | 256KB 를 넘으면 조각으로 나누고 바뀐 조각만 올림 |

localStorage 키는 `pkos.entries.v2` · `pkos.settings.v1` · `pkos.tombstones.v1` · `pkos.draft.v1` · `pkos.folder` · `pkos.connected` · `pkos.token.v1` · `pkos.email` 입니다.
옛 이름(`trace.*` · `peer.*` · `pkems.*`)과 드라이브의 옛 색인 파일은 처음 열 때 이어받습니다 ([docs/개발배경.md](docs/개발배경.md)).

### 데이터 흐름

```
작성 → localStorage(글) + IndexedDB(파일)        ← 브라우저 임시 보관
  ↓ [기록 저장]
기록별 폴더 확보 → 첨부 업로드(청크) → .md 업로드
  → 구글 문서/HTML 사본 → PKOS-index.json 갱신
  ↓ 다른 기기
탭 복귀·포커스·온라인 복귀 시 색인을 다시 읽어 병합 (updatedAt 최신 우선, 삭제는 tombstone)
```
