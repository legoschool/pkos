구글 기록장

PKOS · Personal · Knowledge · Operation · System

수업과 공부, 일상에서 얻은 생각을 사진·링크와 함께 남기는 개인 기록장입니다. 내 구글 드라이브에 기록을 모으고, 관련 내용을 연결해 다시 찾아볼 수 있습니다. 필요한 기록은 복사해 사용 중인 AI에 붙여넣어, 생각을 검토하고 발전시키는 데 활용할 수 있습니다.

내 드라이브에 저장 마크다운 파일 브라우저에서 바로 코드 공개
만든 이유기록을 다시 찾지 못하던 경험에서 무엇을 하나화면과 함께 기능 살펴보기 시작하는 법로그인과 폴더 연결 저장 방식드라이브에 어떻게 남는지 참고사항되지 않는 것과 알아 둘 것 소개PKOS 라는 이름과 지향점

만든 이유

2013년부터 교사로 일하며 수업 자료와 연수 기록을 모아 왔습니다. 자료는 많아졌지만 필요할 때 다시 찾는 일은 쉽지 않았습니다. 컴퓨터와 드라이브, 메신저에 나뉘어 있었고, 파일을 찾아도 당시 어떤 생각으로 만들었는지 기억나지 않는 경우가 있었습니다. 기기 고장이나 계정 변경으로 꺼내 볼 수 없게 된 자료도 있었습니다.

이런 경험을 하면서 지식과 정보를 대하는 방식에 대해 생각하게 됐습니다. 우리는 지식과 정보가 중요한 힘이 되는 사회에 살고 있습니다. 하지만 정작 내가 배운 것, 직접 겪은 일, 문득 떠오른 아이디어를 남기고 다시 활용하는 일은 자주 뒤로 밀립니다. 수업 중 눈여겨본 반응이나 다음에 시도해 보고 싶었던 생각도, 기록하지 않으면 시간이 지나며 흐려집니다.

AI를 활용하면서 이 아쉬움이 더 커졌습니다. 내 자료와 생각을 AI에 제공하면 다른 관점에서 살펴보고 발전시킬 수 있는데, 필요한 기록을 찾아 모으는 데부터 시간이 들었습니다. 자료에 그때의 상황과 판단까지 함께 남아 있었다면 더 구체적인 질문을 할 수 있었겠다는 생각이 들었습니다.

앞으로 AI가 일상의 많은 일을 더 능숙하게 처리하게 될수록, 자신이 겪은 일에서 무엇을 배우고 어떤 질문을 만들어 내는지가 중요해질 것이라고 생각합니다. 교사에게는 교실에서 관찰하고 판단한 경험이, 학생에게는 배우며 궁금해하고 시도한 과정이 있습니다. 이런 경험을 돌아보고 서로 연결하면서 자기만의 관점과 통찰을 키울 수 있어야 합니다. AI와 경쟁해야 하는 상황에서도, 그 바탕에서 AI의 제안을 판단하고 자신의 방향을 정할 수 있기를 바랍니다.

그래서 글과 사진, 링크를 함께 남기고 제 구글 드라이브에 파일로 보관하는 기록장을 만들었습니다. 글은 다른 편집기에서도 읽을 수 있도록 마크다운 형식으로 저장하고, 관련 기록을 연결하거나 필요한 내용을 AI에 제공할 수 있게 했습니다.

저는 이 도구를 통해 각자가 자신의 지식과 경험을 꾸준히 이어 갔으면 합니다. 좋은 생각을 놓치지 않고 남기는 일부터, 지난 기록을 다시 읽고 AI와 검토하며 다음 시도로 발전시키는 일까지 돕고 싶습니다. PKOS는 그런 개인 지식 운영 체계를 만들어 가기 위한 기록 도구입니다.

설계 원칙

필요한 순간에 남길 수 있도록

글과 사진, 링크를 함께 담을 수 있게 했습니다. 분류를 바로 정하기 어려울 때는 미정리함에 두고 나중에 정리할 수 있습니다.

앱 밖에서도 기록을 확인할 수 있도록

저장한 글과 첨부 자료는 사용자의 구글 드라이브에 파일로 보관합니다. 글은 마크다운 형식으로 남겨 다른 텍스트 편집기에서도 읽을 수 있게 했습니다. 다른 편집기에서 고친 내용을 앱에 반영하려면 별도의 가져오기 절차가 필요합니다 (아래 「참고사항」).

생각이 생긴 맥락을 함께 남기도록

내 생각, 자료 인용, AI 답변을 구분하고 관련 기록을 연결할 수 있습니다. 나중에 다시 읽을 때 무엇을 참고했고 어떻게 생각했는지 살펴보기 위한 기능입니다.

다시 활용하는 과정까지 이어지도록

필요한 기록을 모아 읽거나 동료와 공유하고, AI에 제공할 수 있게 했습니다. 다음 시도에서 달라진 점도 함께 남기며 기록을 이어 갈 수 있기를 바랍니다.

만든 이유의 원문과 설계 결정, 개발 연혁은 저장소의 docs/개발배경.md 에 있습니다.

무엇을 하나

항목을 선택하면 기능 설명과 화면 예시를 볼 수 있습니다.

글과 자료를 함께 기록하기

종이 한 장에 글을 쓰면서 사진·링크·파일을 함께 넣습니다. 사진을 붙여넣거나 끌어다 놓으면 커서가 있던 자리에 들어가고, 웹 주소를 붙여넣으면 링크 카드가 됩니다. 빈 줄에서 / 를 치면 소제목·할 일·목록·표·사진 같은 넣을 것을 고를 수 있습니다. 자료 옆에 당시 생각을 덧붙여 둘 수 있습니다.

태그를 나중에 정하고 싶으면 「나중에 정리」를 켜 두면 됩니다. 그 기록은 왼쪽 메뉴의 「미정리함」에 모이고, 태그를 붙이거나 「정리 끝」을 누르면 빠져나갑니다.

쌓이면 이렇게 보입니다

출처 구분하기

인용 상자에 세 가지 표시를 붙일 수 있습니다. 💭 내 생각, 📚 자료 인용(출처를 적는 칸이 있습니다), 🤖 AI 답변(어느 AI인지 적습니다). 나중에 읽을 때 내용의 출처를 확인할 수 있습니다.

AI 답변은 읽는 화면에서 접힌 상태로 표시되고, 눌러야 펼쳐집니다. 시간이 지난 뒤 AI가 한 말을 내 생각으로 착각하지 않도록 한 장치입니다. 저장되는 마크다운에는 옵시디언 콜아웃 표기 (> [!ai]- …)로 남아, 옵시디언에서도 같은 구분이 보입니다.

관련 기록 연결하기

글 속에 [[온도계 사용법]] 처럼 적으면 기록끼리 이어집니다. 다른 기록에서 이 기록을 연결하면, 이 기록을 열었을 때 연결한 기록의 목록이 함께 표시됩니다(백링크). 관계망 화면에서는 점을 이어 연결을 만들고 「여기서 배움」 같은 설명을 붙일 수 있습니다.

폴더 구조 · 드라이브가 지금 어떻게 생겼는지

탐색기처럼 위에서 아래로 펼쳐 봅니다. 「폴더 정리 방식」 설정에 따라 그림이 달라지고, 📝 를 누르면 그 기록이 열립니다. 드라이브에 직접 넣은 파일 이름을 날짜·폴더 이름으로 정리하는 기능도 이 화면에 있습니다.

AI에 건네기

선택한 기록을 복사해 사용 중인 AI(ChatGPT·Claude·Gemini 등)에 붙여넣습니다. 질문할 때 필요한 배경 자료로 활용할 수 있습니다. 이 앱이 AI를 직접 호출하지는 않으며, 복사와 붙여넣기는 사용자가 합니다.

  • 맨 앞에 요청문이 붙습니다. 내 글·자료 인용·AI 답변을 구분해 읽고, 근거에는 기록 번호를 붙여 달라는 내용입니다. 고쳐 쓰고 기본으로 저장할 수 있습니다
  • 기록마다 번호와 id가 붙어, 답변이 어느 기록을 두고 한 말인지 되짚을 수 있습니다
  • 기존 AI 답변 인용은 기본으로 제외합니다. 필요하면 포함할 수 있습니다
  • 사진·파일은 함께 실리지 않습니다. 목록만 적히므로 필요한 것은 따로 첨부합니다

답이 오면 그 기록을 열어 「🤖 AI 답변」 상자로 넣어 두면, 어느 AI의 답인지와 함께 남습니다.

사진 가리기

공유할 사진에서 가릴 부분을 직접 선택합니다. 사진에서 가릴 자리를 누르거나 문지르면 그 부분이 모자이크로 가려지고, 원 크기와 칸 굵기를 고를 수 있습니다. 이미 드라이브에 올라간 사진도 같은 파일에 덮어써 고칠 수 있습니다.

얼굴을 자동으로 찾아 주지는 않습니다. 가린 결과는 올라가는 사진 자체에 적용됩니다. 공유 전에는 빠뜨린 부분이 없는지 사진을 다시 확인하는 창이 뜹니다.

휴대폰 공유 메뉴로 담기 (안드로이드)

안드로이드 휴대폰에서 이 기록장을 「홈 화면에 추가」로 설치하면 공유 메뉴에 「구글 기록장」이 나타납니다. 인터넷·유튜브·사진첩에서 「공유 → 구글 기록장」을 누르면 제목·주소·사진이 작성 화면에 들어옵니다. 아이폰의 사파리는 이 방식을 지원하지 않으므로, 주소를 복사해 붙여넣거나 사진첩에서 골라 넣습니다. 컴퓨터에서는 웹페이지 주소를 복사해 종이에 붙여넣으면 링크 카드가 됩니다.

손 메모

손가락·마우스·태블릿 펜으로 쓰고 그린 것을 그림 한 장으로 넣습니다. 펜은 누르는 세기에 따라 굵기가 달라집니다.

녹음 · 받아쓰기

말한 내용을 소리 파일로 담고, 브라우저의 음성 인식으로 글로 옮겨 적습니다. 별도의 API 키 입력 없이 사용할 수 있습니다. 받아 적은 글은 틀린 곳을 확인하고 고쳐 두는 편이 좋습니다.

전체 보기 · 링크로 공유

한 편을 펼쳐 읽고, 거기서 인쇄(PDF)·구글 문서·마크다운 원본·드라이브 폴더로 이동합니다. 「🔗 링크로 공유」에서는 웹 쪽으로 · 구글 문서 웹 페이지로 · 구글 문서 파일 · 폴더 통째로 중 하나를 고릅니다. 누르는 순간 그 기록의 드라이브 권한이 「링크가 있는 사람 · 읽기」로 바뀌고 주소가 복사됩니다. 받는 사람은 로그인 없이 열 수 있습니다.

사진이 든 기록은 공유 전에 사진을 다시 보여 주고 「확인했습니다」 체크를 받습니다. 링크는 「공유 끄기」로 되돌릴 수 있지만, 이미 전달된 링크까지 거둘 수는 없습니다.

기록 모아 보기 · 엮어내기

태그나 검색으로 거른 기록을 골라 한 파일로 내려받습니다. 마크다운(.md)과 HTML 두 형식이며, HTML은 표지와 목차가 붙어 인쇄하면 책처럼 나옵니다. 연결된 기록을 한 단계 더 넣을 수도 있습니다.

휴대폰에서도 같은 화면

  • 자동 동기화 · 휴대폰에서 쓰고 PC로 돌아오면 최신 목록을 다시 읽어 옵니다
  • 삭제도 전파 · 휴대폰에서 지운 기록이 PC에서 되살아나지 않습니다
  • 연결이 끊긴 상태에서 써 두면 나중에 연결됐을 때 올라갑니다
  • 업로드 이어 올리기 · 진행률이 표시되고, 끊기면 받은 자리부터 다시 시도합니다
  • 로그인 유지 · 새로고침해도 유지되며, 열쇠가 만료되면 「다시 연결」 한 번으로 이어집니다

시작하는 법

링크를 받은 분과 직접 사본을 만들어 나눠 줄 분의 절차가 다릅니다.

🅐 링크를 받았다면

따로 설치할 것은 없습니다. 처음 한 번만 아래를 해 두면 됩니다.

  1. 기록장을 열고 「구글 로그인」을 누릅니다

    앱을 만든 사람의 설정에 따라 「Google에서 확인하지 않은 앱」이라는 화면이 나올 수 있습니다. 앱 이름과 요청하는 권한(앱이 만들거나 고른 드라이브 파일)을 확인한 뒤, [고급] → [이동] 을 눌러 진행합니다.

  2. 설정에서 저장할 폴더를 정합니다

    「⚙️ 설정 → 저장 위치」에서 「＋ 새 폴더 만들기」 또는 「📂 폴더 고르기」를 누릅니다. 위쪽 띠가 초록색으로 바뀌고 폴더 이름이 보이면 연결된 것입니다.

  3. 제목과 내용을 쓰고 「기록 저장」을 누릅니다

    작성 중인 내용은 이 브라우저에 임시 보관됩니다. 구글 드라이브에 저장하려면 「기록 저장」을 눌러야 합니다. 저장 상태는 카드의 「☁ 저장됨」 표시로 확인하고, 다른 기기에서도 기록이 열리는지 한 번 봐 두면 좋습니다.

  4. 안드로이드 휴대폰이라면 「홈 화면에 추가」까지

    앱으로 설치해 두면 공유 메뉴에 「구글 기록장」이 나타나, 인터넷·유튜브·사진첩에서 바로 담을 수 있습니다. 아이폰 사파리는 이 방식을 지원하지 않습니다.

🅑 직접 사본을 만들어 나눠 주려면

이 앱은 드라이브 전체가 아니라 이 앱이 만들거나 사용자가 직접 고른 파일에만 접근하는 권한 (drive.file)을 씁니다. 연수나 학교 단위로 나눠 줄 계획이라면 사본을 만들어 로그인 설정을 직접 관리하는 편이 좋습니다. 필요한 것은 GitHub 저장소와 구글 클라우드 프로젝트입니다.

  1. GitHub 저장소를 만들고 GitHub Pages 를 켭니다

    내계정.github.io/저장소이름/ 으로 열립니다.

  2. 구글 클라우드에서 Drive API 와 Picker API 를 켜고, 클라이언트 ID 와 API 키를 만듭니다

    요청 권한은 openid, userinfo.email, drive.file 세 가지입니다. 「승인된 자바스크립트 원본」에는 내 주소의 앞부분만(경로 없이) 넣습니다.

  3. index.html 맨 위의 OWNER_CLIENT_ID 와 OWNER_API_KEY 를 내 값으로 바꿉니다

    둘 다 공개용 식별자라 코드에 있어도 됩니다. 클라이언트 보안 비밀번호는 쓰지 않습니다.

🚚 클릭 순서와 화면 캡처까지 적은 전체 안내가 저장소의 SETUP.md 에 있습니다.

저장 방식

저장한 기록은 지정한 드라이브 폴더에 보통의 파일로 남습니다. 폴더를 열면 아래처럼 보입니다. 

내가 지정한 폴더/

│   ├── 2026-08-17_수업설계_물의 상태변화 수업      ← 구글 문서 (읽기 좋게)
│   ├── 2026-08-17_수업설계_물의 상태변화 수업_칠판 정리_01.jpg
│   └── 2026-08-17_수업설계_물의 상태변화 수업_학습지_02.pdf
├── 2026-08-14_수업설계_온도계 바르게 읽는 법/

└── PKOS-settings.json    ← 내 유형·이름 규칙·보기 설정

임시 보관과 드라이브 저장

작성 중인 내용은 브라우저가 몇 초마다 임시 보관합니다. 창이 닫혀도 같은 브라우저에서 다시 열면 이어 쓸 수 있습니다. 드라이브에 올라가는 것은 「기록 저장」을 누른 뒤이며, 임시 보관은 그 기기의 브라우저 안에서만 유효합니다. 드라이브에 저장된 파일을 내 컴퓨터에도 두려면 구글 드라이브 데스크톱 앱으로 그 폴더를 동기화합니다.

이름만 보고도 알 수 있게

파일 이름은 기본이 날짜 + 태그 + 제목 + 자료 제목 + 번호 입니다. 사진마다 제목을 적으면 이름에 들어가고, 쓰지 않은 자리는 빠집니다. 「설정 → 파일 이름」에서 어떤 조각을 넣을지 정합니다.

폴더 정리 방식

「설정 → 저장 위치」에서 기록마다 폴더 하나(기본)와 한 폴더에 전부 중 고릅니다. 이전 판에서 쓰던 방식(글과 자료 분리 · 월별 폴더 · 태그가 곧 폴더)을 쓰고 있었다면 그 방식이 그대로 유지되고, 같은 화면에 「지금 쓰는 방식」으로 표시됩니다.

글은 텍스트로 남습니다

본문은 마크다운(.md)이라 메모장으로도 열립니다. 읽기 편하도록 구글 문서 사본도 함께 만들 수 있습니다 (설정에서 끌 수 있습니다). 드라이브 데스크톱 앱으로 동기화한 폴더를 옵시디언에서 「폴더를 볼트로 열기」 하면 링크·백링크·그래프 뷰가 동작합니다.

참고사항

이용 전에 알아둘 기능의 범위와 제한입니다.

아이들 사진

얼굴을 자동으로 찾아 가려 주지는 않습니다. 「사진 가리기」로 가릴 부분을 직접 고르고, 공유 전에는 사진을 다시 보여 주는 확인 창을 거칩니다. 가린 사진은 같은 파일에 덮어쓰지만 드라이브의 「버전 기록」에는 이전 사진이 남을 수 있으니, 완전히 없애려면 드라이브에서 이전 버전을 지웁니다.

그 밖에 알아 둘 것

항목내용
저장 작성 중인 글은 브라우저 임시 보관, 드라이브 저장은 「기록 저장」을 눌렀을 때. 임시 보관은 그 기기에서만 유효합니다
보이는 파일 앱이 만든 파일과 고르기 창에서 직접 고른 파일만 보입니다. 드라이브에 손으로 넣어 둔 파일은 「설정 → 가져오기 → 드라이브에서 파일 고르기」로 한 번 골라야 합니다
외부 편집 드라이브의 .md 를 다른 도구에서 읽는 것은 자유롭지만, 파일 이름을 바꾸거나 옮기면 목록과 어긋납니다. 다른 도구에서 고친 내용을 앱에 반영하려면 「폴더 훑어서 가져오기」를 씁니다
파일 크기 하나당 200MB 까지입니다. 긴 영상은 유튜브에 「일부공개」로 올리고 「코드 삽입」에 주소를 넣는 편이 낫습니다
녹음 녹음 화면을 열어 둔 동안 녹음됩니다. 기기와 브라우저에 따라 화면을 벗어나면 녹음이 중단될 수 있습니다. 받아쓰기는 크롬에서 가장 잘 되고, 결과는 확인이 필요합니다
휴대폰 공유 메뉴 안드로이드에서 앱으로 설치했을 때 나타납니다. 아이폰 사파리는 지원하지 않습니다
로그인 유지 구글이 주는 열쇠는 1시간짜리입니다. 만료되면 「다시 연결」을 한 번 누릅니다. 기록은 그대로 있습니다
실행 환경 로그인·캡처·녹음은 https:// 또는 localhost 에서만 됩니다. file:// 로 열면 막힙니다
HTML 공유 드라이브는 HTML 파일을 웹페이지로 열어 주지 않습니다. 사람에게 보여 줄 것은 구글 문서나 「웹 쪽으로」 공유를 씁니다
🔒 개인정보. 기록은 각자의 구글 드라이브와 브라우저에 저장되며, 운영자에게 전송되지 않습니다. 이 앱은 자신이 만들었거나 사용자가 고른 파일만 읽고 씁니다. 연결을 끊으려면 구글 계정 → 타사 앱 액세스 에서 철회하면 됩니다. 글꼴·링크 미리보기·받아쓰기가 외부와 통신하는 범위는 개인정보처리방침 에 적어 두었습니다.

소개

PKOS

Personal  ·  Knowledge  ·  Operation  ·  System

개인 지식 운영 체계

PKOS는 Personal Knowledge Operation System의 약자로, 개인의 지식과 경험을 남기고 활용하는 체계를 뜻합니다. 기록을 찾아 읽고, 관련 내용을 연결하고, AI와 검토한 뒤 실제로 시도한 결과를 다시 남기는 과정을 돕고자 붙인 이름입니다.

지향하는 것은 각자가 자신의 경험을 바탕으로 생각을 발전시킬 수 있는 환경입니다. 현재의 구글 기록장은 그 환경을 만들어 가기 위한 도구이며, 제 수업과 공부에서 필요한 기능을 중심으로 다듬고 있습니다.

여기서 「운영 체계」는 컴퓨터의 운영체제가 아니라, 개인의 지식과 경험을 계속 활용하기 위한 방식과 도구를 가리키는 이름입니다.

코드는 공개되어 있습니다

저장소는 누구나 볼 수 있게 공개해 두었고, 학교와 연수에서 사본을 만들어 쓰기를 바라며 만들었습니다. 주요 기능은 index.html 한 파일에 모아 두었습니다. 이용 조건(라이선스)은 저장소에 별도로 밝힐 예정이며, 가져다 쓰거나 고쳐 쓸 때는 만든이를 함께 적어 주세요.
